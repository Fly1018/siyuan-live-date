# 动态日期 (siyuan-live-date)

让**指定文档 / 笔记本**里的日期"活着"：今天打开显示今天，明天打开显示明天。**只改显示，不改数据** —— 笔记文件里存的仍然是你写的标记。

## 生效范围（满足其一即可）

1. **文档开关**：文档块上添加属性 `custom-live-date = on`。
2. **笔记本白名单**：在 **插件设置** 里填写笔记本 ID（一行一个，默认为空）；
   也可以直接点设置里的「加入当前文档所在笔记本」按钮，把当前文档所在笔记本填进去。

想停用某篇文档：属性值改成 `off`、`false` 或删掉，然后重开一次文档（结论缓存最多 3 秒 / 1 分钟）。
想停用某个笔记本：在设置里删掉对应 ID 并点确定（会立即清缓存生效，不用重载插件）。

## 用法

### 行内标记（保留排版）

- `@today` → `2026-09-26`
- `@now` → `2026-09-26 12:30:45`

例如 `**【@today】**` 渲染出来是 `【2026-09-26】`，加粗、括号都不丢；斜杠指令 `/dqr` 可快速插入 `【@today】`。

### 块属性

给一个只放日期的块加属性 `custom-live-date`，值留空（或写 `on`）按 `yyyy-MM-dd` 渲染，
也可以写 `yyyy年MM月dd日`、`yyyy-MM-dd HH:mm` 自定义格式。插件把该块第一个文本节点刷成当天日期。
属性存在块数据里，所以即使某次被存成了死日期，下次渲染也会自动纠正。

支持的格式占位符：`yyyy` `yy` `MM` `dd` `HH` `mm` `ss` `ECN`(星期几)

## 设置

设置 → 集市 → 已下载 → 动态日期（齿轮图标）：

- **生效笔记本**：白名单，一行一个笔记本 ID（留空 = 只靠文档属性生效）
- **调试日志**：默认关闭；打开后把每次实际替换写进 `data/storage/petal/siyuan-live-date/debug.json`
- **快捷操作**：「加入当前文档所在笔记本」按钮

## 已知边界

1. **只改显示，不改数据**：笔记文件里存的仍是 `@today`。但如果你在那一行里打字并保存，
   思源会把当前显示（某天的日期）当成内容存下来，标记就没了，需要重新打一次。
2. **不碰代码块 / 公式块 / HTML 块**：这些容器里的 `@today` 不会被替换（避免污染数据）。
3. 导出 PDF/图片、安全模式、连接远程内核时不生效（插件本身不加载）。
4. 渲染时机是"文档加载完成"以及"文档有改动后 0.6 秒"，所以刚打开时会有一瞬间显示 `@today`。
5. 文档开关需要一次 `/api/attr/getBlockAttrs` 调用，结果缓存：未生效 3 秒、已生效 60 秒。

## 排障

在设置里打开**调试日志**后，插件会把每次实际替换写进
`data/storage/petal/siyuan-live-date/debug.json`（最多 30 条，5 秒合并写一次）：

```json
["2026-09-26T08:55:32.097Z onload",
 "2026-09-26T08:55:44.055Z render doc=20260926164351-yl4klgk markers=1 attrs=0"]
```

- 只有 `onload` 没有 `render` → 说明该文档不在生效范围，或没找到标记；
- 出现 `gate-error` → 读属性失败，此时会"放行"（照常渲染）；
- 长期稳定后，可以在设置里把调试日志关掉，就不再写这个文件。

## 开发与发版

**仓库根目录就是插件本体**：思源直接加载 `index.js`（CommonJS，`require("siyuan")`），
不需要编译或构建，改完保存即可生效。完整的版本记录见 `CHANGELOG.md`。

```bash
python3 scripts/pack.py          # 校验并打出 package.zip
python3 scripts/pack.py --check  # 只校验，不生成
```

发版步骤：

1. 改 `plugin.json` 里的 `version`，并在 `CHANGELOG.md` 补一条；
2. 提交，打一个与版本号一致的 tag 并推送：

   ```bash
   git tag v0.6.1 && git push origin v0.6.1
   ```

3. GitHub Actions 会校验 tag 与版本号一致 → 打包 `package.zip` → 发布 Release。

集市索引会在 1–3 小时内自动拉到新版本，**不需要再提 PR**。
若集市长时间不更新，先看仓库有没有带 `stage-fail` 标签的 issue —— 多半是
`plugin.json` 的 `version` 没提升，或 tag 与版本号不一致（工作流会直接把这一种拦下来）。
